SOFER STUDIO — OFFLINE FOR WINDOWS 64-BIT

1. Extract the whole ZIP to a writable folder, such as Documents\Sofer Studio.
2. Double-click Start Sofer.cmd. Your browser opens the local program.
3. Keep the program window open while working; close it when finished.

No installation, administrator rights or internet connection is required.
The download includes Node.js, the STaM font, the Torah corpus and Tefillin passages.
It does not include anyone's online saved work. Your offline profiles, sources
and layouts are saved in sofer-studio\data\sofer.db inside this folder.

BACKUP: Close the program and copy the entire extracted folder somewhere safe.
UPGRADE: Extract a new version into a NEW folder. With both versions closed,
copy the old sofer-studio\data folder into the new sofer-studio folder before
opening the new version. Keep the original folder as your backup.

PRINT: Use Download > Print / Save PDF. Tefillin can place all four passages on
one A3 or A4 landscape sheet, at their chosen physical widths. Print at 100%
and verify dimensions with a ruler. Review text and calibration before writing.

The program listens only on this computer (127.0.0.1). Browser extensions and
the browser itself are independent of the offline program.
Licenses for Node.js, the bundled libraries, fonts and source text are included.
