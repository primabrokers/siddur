## What to Build

### 1. Database (sofer-studio/db/schema.js)

### 2. Layout Engine (sofer-studio/engine/)

**width.js** — Width calculation:
- skeletonWidth(letter, profile) = referenceSkeletonWidth * (letter_height_mm / reference_height_mm)
- strokeContribution(letter, profile) = stroke_mm * strokeFactor(letter)
- totalWidth(letter, profile) = skeletonWidth + strokeContribution
- Skeleton EXCLUDES stroke. Stroke added ONCE. Never double-counted.
- Fixture that MUST pass: Reference letter skeleton 2.0mm at ref height 3.0mm, at 4.5mm master = skeleton 3.0mm. +0.2mm stroke = 3.2mm total. Stroke 0.3mm = 3.3mm. Scale unchanged.
- Unit<->mm conversion: 1 unit = N mm (default 0.5mm). Letter widths stored in units, converted to mm.

**shem.js** — Sacred name detection:
- Detect: Tetragrammaton, Elohim/Elokeinu, El/Elokai/Elyon, Shaddai, Tzevaot, Adonai, and variants WITH prefixes
- Normalized view for detection; source characters NEVER rewritten
- Whole token atomic — never split across lines
- Shem letters excluded from stretch candidates
- If Shem token > available line width: unsatisfiable error. Never truncate.
- Uncertain classification: explicit flag

**layout.js** — Line-fitting and layout:
- RTL word-by-word. Never split words.
- Petucha: ends line, rest blank. Setuma: 9-letter-width gap mid-line, configurable.
- Group into amudim. Vavei ha'amudim: flag columns not beginning with vav.
- Min column width = 3 * wordWidth("LMSHPCHTKM") + 2 * interWordGap (INCLUDES 2 inter-word gaps)
- Flag lines exceeding max letter count. Distinguish Hebrew letters from combining marks (Intl.Segmenter).
- Stretch/justify: leftover per line. Default stretchable: Dalet Heh Chet Lamed Resh Tav plus Bet Kaf Mem Sofit Samech. Non-stretchable default: Yud Vav Zayin Nun Sofit Nun Sofit Gimmel Tzadi Tzadi Sofit (overridable). Max stretch per letter HARD CAP. Position filter: word_final/line_end/anywhere. Auto-suggest distributes evenly preferring line-end.
- Column geometry: inkExtent = (L-1)*P + H. allocatedRulingHeight = L*P. Label trailing space. Reject pitch < letter_height. Derive amud height, amudim per yeria, total yerios, klaf length metres. Partial final yeria: round_up or exact.
- Fixed passage patterns: slots/segments/gaps, provenance, version. Exempt from ordinary wrapping. Missing data = fail-closed blocker.
- Unusual letters: large/small/dotted/broken/suspended, occurrence overrides, stable IDs. Taggin toggle visual only.
- Chunked computation for large sources. Show progress.

**validate.js** — Line validation:
- Underfull, overfull, conflicting bounds, Shem too-wide, min column width, letter count
- Spacing limits: minInterLetterGap, minInterWordGap, maxInterWordGap (relative to small-letter ref)
- Setuma at line edge. Impossible combinations rejected. Validate every line and export.

**search.js** — Verse search: by ref, return amud/line positions, verses spanning lines return ranges.

**compare.js** — Profile comparison: 2-3 profiles, same source+geometry, independent results, honest labels.

**source.js** — Source text processing: accept TXT/JSON/paste, strip nekud for consonant view but preserve original, parse markers, compute hash, keep unusual-letter dots as metadata, count letters/words, label excerpts honestly.

## CRITICAL CONTRACT CORRECTIONS (applied to API_CONTRACT.md)
1. klaf_length_m = sum of sheet WIDTHS / 1000 (NOT height x count). For k columns per yeria: fullYeriaWidth = 2*outer_margin + k*line_width + (k-1)*inter_column_gap. Exact-final-sheet uses remaining columns. Test independent fixtures.
2. amudim_per_yeria is a configurable positive integer from geometry settings — do NOT hard-code 2.
3. New endpoints: POST /api/layouts/:id/stretch (manual stretch, hard cap, no Shem, frozen on lock), POST /api/layouts/:id/auto-suggest (suggestions only), POST /api/layouts/:id/adopt-candidate (never silently carry progress to changed lines, only verified-unchanged lines keep status).
4. layout_lines table includes stretch_decisions JSON and leftover_mm REAL.
5. Lock enforcement covers stretch edits — frozen as part of immutable snapshot.
