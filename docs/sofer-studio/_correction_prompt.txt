### ENGINE DEFECTS

**E1. Shem coverage (engine/shem.js)**
Missing names: יה, אהיה, אלוה, אלהיכם, אלהיהם, באלהיכם, ובאלהיכם, and all suffixed forms of elohim (אלהיכם, אלהיהם, אלהינו, אלהיך, אלהי, etc.). Add these per Yesodei HaTorah 6:2-4. Conservative: uncertain flag for homographic forms, but still protected (never split/stretched). Add source-annotation overrides. Add meaningful failing test cases.

**E2. Stretch duplicate/idempotency (engine/layout.js applyStretch)**
- Duplicate decisions for same occurrence each below cap can sum above cap. Must aggregate per occurrence BEFORE cap checking.
- Applying same decision twice subtracts from already-reduced leftover. Must always recompute from immutable BASE width.
- Repeated replacement of decision set must be idempotent.
- Manual requests must obey active position filters.
- Unknown/Shem/overcap requests must fail ATOMICALLY (not partial success).
- Test: duplicate 1mm for one occurrence with 1.5mm cap must reject or aggregate then enforce total cap.

**E3. Pattern integration (engine/layout.js)**
- computeLayout NEVER calls resolvePatternsForSource or renderPattern. Must integrate: when patterns are selected, verses in pattern ranges use renderPattern, not ordinary wrapping.
- renderPattern currently has words:[], shem:false, drops positions/segments/gaps, adds trailing word gap. Must preserve real source tokens, occurrence IDs, Shem flags, and slot segment geometry.
- Ensure exact source coverage (no omissions, duplicates, substitutions). Reject unsupported data clearly.
- Known source ranges must NOT silently wrap when patterns selected.

**E4. Marker positioning (engine/layout.js buildWordUnits)**
- buildWordUnits skips every inline marker then emits only verse.after at end. For "אב {ס} גד" the boundary must remain BETWEEN those words, not at verse end.
- setuma at start currently pushes gap with currentWidth=0. Test gap measured exactly once, not supplemented by unintended word gaps.

**E5. Unusual letter mapping (engine/layout.js, engine/source.js, engine/text.js)**
- processSource drops occurrence_index. Must preserve it.
- resolveOverrides resets letter counts for EACH WORD and defaults to matching ALL occurrences of same base. One selected occurrence must affect ONLY that occurrence using stable source occurrence ID.
- Repeated same letters in multiple words of one verse must be a test case.
- U+05C4 (U+05C4 = Hebrew dot above/left) and U+05C5 dots are stripped in text.js before metadata extraction. Must preserve metadata from RAW source FIRST, then strip for working view.

**E6. Source object import (engine/source.js)**
- Preserves only joined verse text as original/hash, losing structured refs/metadata. Must retain canonical complete object plus original transport string, OR reject object form and require exact raw JSON string.
- Add specific qere/ketiv warning when bracketed alternatives detected.
- Do not certify bracketed study text.

**E7. Chunked progress (engine/layout.js)**
- onProgress callbacks in synchronous loop do NOT yield event loop. For full ~305k letter workload, implement actual yielding (setImmediate/queueMicrotask chunks or worker_thread). UI progress must reflect actual progress.

**E8. max_inter_word_gap enforcement (engine/validate.js)**
- 99mm max against 1.2mm small letter produces no error. Must enforce configured max strictly below calibrated small-letter width, even if current word gap itself is smaller. Reject impossible combinations.
