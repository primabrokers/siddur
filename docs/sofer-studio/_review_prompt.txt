## Review Areas (verify each against ACTUAL code, not just test pass/fail)

### 1. Width & Scaling
- One letter-height master scale, proportional widths, separate stroke, hard caps
- Fixture: 2.0mm ref at 3.0mm → 3.0mm at 4.5mm; +0.2 stroke = 3.2; +0.3 = 3.3
- Units ↔ mm conversion visible and editable
- Min practical LETTER HEIGHT warning (not nib)

### 2. Shem Protection
- All forms: יהוה, יה, אהיה, אלוה, אלהים + suffixed/prefixed forms
- Whole token atomic, never split, never stretched
- Uncertain classification explicit (homographs flagged for review)
- Source-annotation overrides
- If Shem > line width: unsatisfiable error, never truncate

### 3. Stretch & Justification
- Duplicate decisions aggregate per occurrence, enforce total cap atomically
- Leftover recomputed from immutable BASE width (idempotent replacement)
- Summed expansions must NOT exceed line's remaining width (total geometry limit)
- Position filters enforced (word_final, line_end, anywhere)
- Unknown/Shem/overcap fail atomically
- Auto-suggest never exceeds cap, never includes Shem
- Manual stretch UI with per-letter steppers, leftover display

### 4. Patterns (CRITICAL)
- computeLayout must actually route patterned verses through renderPattern
- renderPattern must preserve real source tokens, occurrence IDs, Shem flags, segment gaps
- Coverage check after ALL slots, not inside each slot
- Preserve exact source reading order (not multiset match)
- Explicit segment gaps retained as positioned items, not just width
- Occurrence overrides applied in fixed rendering
- KNOWN special passages (Exodus 15, Deut 32, Num 10:35-36) must NEVER silently use normal wrapping even without selected pattern — absence of reviewed pattern metadata is a BLOCKER, not permission for normal wrapping
- Study preview must be explicitly blocked/watermarked as such

### 5. Markers & Spacing
- Petucha/setuma markers positioned BETWEEN words, not at verse end
- Leading setuma gap measured exactly once
- min/max inter-letter and inter-word gaps enforced
- maxInterWordGap strictly below calibrated small-letter width (not equal)
- Setuma at START of line detected as edge error (not just last-item check)
- Setuma gap = 9 letter widths, configurable, reference letters defined
- Impossible combinations rejected explicitly

### 6. Unusual Letters
- Per-occurrence override using stable source occurrence ID
- Only selected occurrence affected (not all same-base)
- U+05C4/U+05C5 dots preserved as metadata from RAW source before stripping
- Occurrence_index preserved through import
- Optional taggin display toggle (visual only, does not alter measurements)
- Large/small/dotted/broken/suspended letter representations in output

### 7. Source Handling
- Raw original preserved exactly
- Consonant-only view derived (not rewrites source)
- Qere/ketiv: bracketed alternatives detected and warned HONESTLY
- Warning must not claim normalization that wasn't performed
- Unresolved variants block writing-ready output
- Source hash (SHA-256) for immutable snapshot
- Excerpt labels honest, never full-Torah totals from excerpts
- Built-in full study-text import from docs/sofer-studio/source-data/
- Study text labeled as study text, NOT certified scribal source

### 8. Persistence & Locking
- Layout lines persist FULL data: words, items, letter measures, Shem flags, occurrence IDs, stretch positions, pattern segments/annotations
- Cannot reconstruct from changed live profile — use saved snapshot
- Server-side lock: marking any line "written" locks entire layout
- Direct API requests to change locked layout → 409
- Stretch on locked layout → 409
- Candidate separate from locked original
- Stable line IDs across reruns
- Progress never silently moves to changed lines

### 9. Candidate & Diff
- Candidate uses snapshot profile/geometry, not live
- Candidate includes pattern/annotation data
- Adoption: server independently verifies unchanged geometry/content before carrying progress
- Only geometrically unchanged lines keep status (server-enforced, not client-trusted)
- Diff reports measurement changes even if word boundaries identical
- Adopted layout preserves summary totals, not empty {}

### 10. recomputeFullLines Problem
- Stretch/auto-suggest must use SAVED measured line and snapshot, not recompute from live profile
- Do NOT reflow on a stretch edit
- Pattern IDs must be wired into recompute if recompute is used at all

### 11. Performance

- Verify unrelated request served DURING large computation
- Compare/candidate routes also async
- Source import doesn't block materially
- UI progress reflects actual progress, not animation
