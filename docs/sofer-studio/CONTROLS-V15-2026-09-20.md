# Sofer controls and Tikkun release — 20 September 2026

The setup screen now uses the requested 45 cm Torah defaults: 125 mm column
width, 7.5 mm line height, 60/75 mm top/bottom margins, 30 mm outer margin,
four amudim per yeria, and 2.5-unit letter height. Custom line counts stay
editable even when the current number matches a preset.

Removed the requested spacing/reference controls, duplicate height results,
skeleton-unit input, stroke/skeleton millimetre columns, and calculation,
distribution, cap-mode and stretch-position selectors. Working profiles use
table units, equal-percentage distribution within the existing preference
groups, and stretching anywhere on the line. Per-letter caps, preferences,
special-space measurements, human holy-letter protection and paragraph rules
remain available. Older profiles adopt the fixed choices in an unsaved draft;
no saved record or layout snapshot is migrated by loading this release.

Tikkun shows Roman line numbers (I, II, III) at the far right, then the original
unit shortage (ש״ת, ח״א, ח״ב, etc.), then the text. Fractional units are retained;
overfull original lines use י״. Shortage comes from the immutable original gap,
not the remaining gap after stretching. The paper is white with no ruling,
word-box or text-margin grid. All pages occupy a vertical scroll track, with
nearby pages rendered lazily. Page navigation, zoom, exact measured glyphs,
section guides, line editing and full-document print preparation remain.
